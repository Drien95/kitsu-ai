# FAQ

| Problème | Solution |
|---|---|
| « Windows a protégé votre ordinateur » | L'installateur n'est pas signé. **Informations complémentaires**, puis **Exécuter quand même**. |
| Pas de cadre vert « Calcul du PC » en combat | Vérifie que KitsuAI tourne (icône près de l'horloge), que Tampermonkey a l'accès à 127.0.0.1, et l'onglet Santé du dock. |
| Onglet Santé : « moteur du PC pas à jour » | Le jeu a été mis à jour. Panneau, **Mettre à jour le moteur**, puis **Recharger le moteur**. |
| « Le port 47123 est peut-être utilisé » | Une autre copie tourne déjà (ancien `KitsuAI.bat`, autre fenêtre). Ferme-la, puis relance KitsuAI. |
| L'analyse ne voit pas mes cartes | Exporte de nouveau ta sauvegarde (onglet Santé du jeu) et glisse-la dans le panneau. |
| L'analyse est longue | Option niveaux « actuels » (2 fois plus rapide), ou moins de cartes. Le cache accélère les analyses suivantes. |
| Je veux tout remettre à zéro | Quitte KitsuAI et supprime le dossier `%APPDATA%\KitsuAI`. |
